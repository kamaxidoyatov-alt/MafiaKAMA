# 🎭 MafiaBOT — Telegram бот для игры «Мафия»

Полноценный Telegram-бот для классической игры «Мафия» с 60 AI-агентами, веб-админкой, рейтинговой системой и Docker-деплоем.

## ✨ Возможности

### 🎮 Игровая система
- Создание публичных и приватных комнат
- Автоматический старт игры при наборе игроков
- Полноценные дневные и ночные фазы
- Система голосования и исключения игроков
- Автоматическая проверка условий победы
- Восстановление игр после перезапуска сервера

| 🔪 Мафия | Мафия | Убивает ночью |

### 🤖 60 AI-агентов
- Уникальная личность и стиль общения у каждого
- Собственная память и история действий
- Анализ чата и построение подозрений
- Принятие решений через LLM (OpenAI/Gemini/Claude)

### 📊 Админ-панель

- Бан/разбан игроков

- Elo-подобная система рейтинга
- Статистика по ролям
- Топ игроков
- История рейтинга

## 🛠️ Технологии

- **Node.js** — серверная платформа
- **Express.js** — HTTP сервер
- **Socket.IO** — WebSocket для real-time обновлений
- **MongoDB + Mongoose** — база данных
- **Redis** — кэширование (опционально)
- **node-telegram-bot-api** — Telegram Bot API
- **OpenAI / Gemini / Claude** — LLM для AI-агентов
- **Docker + Docker Compose** — деплой
- **Winston** — логирование
- **EJS** — шаблоны админ-панели

## 🚀 Быстрый запуск

### 1️⃣ Через Docker (рекомендуется)

```bash
# Клонируйте репозиторий
git clone https://github.com/yourusername/mafia-bot.git
cd mafia-bot

# Настройте переменные окружения
cp .env.example .env
# Отредактируйте .env — вставьте BOT_TOKEN и API ключи

# Запустите все сервисы
docker compose up -d

# Проверьте логи
docker compose logs -f app
```

### 2️⃣ Локальный запуск

**Требования:** Node.js 20+, MongoDB, Redis (опционально)

```bash
# Установите зависимости
npm install

# Настройте .env
cp .env.example .env
# Отредактируйте .env: BOT_TOKEN, MONGODB_URI и др.

# Запустите в режиме разработки
npm run dev

# Или production
npm start
```

## ⚙️ Конфигурация

Основные переменные окружения (`.env`):

| Переменная | Описание | По умолчанию |
|-----------|----------|-------------|
| `BOT_TOKEN` | Токен Telegram бота | **обязательно** |
| `MONGODB_URI` | Подключение к MongoDB | `mongodb://localhost:27017/mafia` |
| `OPENAI_API_KEY` | OpenAI API ключ | для AI-агентов |
| `LLM_PROVIDER` | Провайдер LLM | `openai` |
| `PORT` | Порт сервера | `3000` |
| `MIN_PLAYERS_TO_START` | Мин. игроков | `4` |
| `MAX_PLAYERS` | Макс. игроков | `16` |

## 🤖 Команды Telegram бота

| Команда | Описание |
|---------|----------|
| `/start` | Запустить бота и зарегистрироваться |
| `/create` | Создать игровую комнату |
| `/join [код]` | Присоединиться к комнате по коду |
| `/rooms` | Список публичных комнат |
| `/profile` | Моя статистика |
| `/rating` | Топ игроков |
| `/rules` | Правила игры |
| `/help` | Помощь |
| `/admin` | Админ-панель |
| `/ban [id] [причина]` | Забанить игрока (админ) |
| `/unban [id]` | Разбанить игрока (админ) |

## 🌐 API Endpoints

- `GET /health` — Health check
- `GET /api/rooms` — Список комнат
- `GET /api/rooms/:code` — Информация о комнате
- `GET /api/players/:id` — Профиль игрока
- `GET /api/games/:id` — Информация об игре
- `GET /api/stats` — Статистика системы
- `GET /api/stats/leaderboard` — Топ игроков
- `GET /admin` — Админ-панель
